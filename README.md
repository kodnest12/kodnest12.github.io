# KodNest Apps

Official website of **KodNest Apps** — an independent Android studio from Pakistan, behind [Expenzee](https://play.google.com/store/apps/details?id=com.kodnest.expenzee) (expense tracker, budget planner & bill splitter) and **Quran Kareem** (read · listen · reflect).

## Portfolio

- **Expenzee** — Finance · Kotlin · Jetpack Compose · Firebase
- **Quran Kareem** — Islamic app · Full Mushaf · Audio recitation

## Publishing

The site is built for free hosting on GitHub Pages:

1. Push to `main` (repo root)
2. **Settings → Pages → Deploy from a branch → main / (root)**
3. Live at `https://kodnest12.github.io/Kodnest-Technoloty/`
